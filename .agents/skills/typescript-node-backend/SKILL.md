# TypeScript Node backend

Use for routes, application services and domain contracts in the current Node HTTP
server. Query Graphify, then inspect the exact route and contract involved.

Validate external input before use, return deliberate error responses, keep domain
types independent of HTTP details, and retain source status in API outputs. Run
`npm run typecheck` and `npm test` after modifications.
