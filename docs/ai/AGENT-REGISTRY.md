# Registro de agentes

| Rol | Cuándo usarlo | Alcance |
| --- | --- | --- |
| Arquitectura | límites o decisiones duraderas | puede escribir ADR/código autorizado |
| Backend | API y motor TypeScript | puede escribir y probar |
| Dominio de viajes | scoring, fechas y variantes | puede escribir y probar |
| Integración de proveedores | APIs externas | investiga y escribe con autorización |
| UX | búsqueda y resultados | solo trabajo de interfaz |
| QA | estrategia y regresiones | pruebas; no presenta mocks como live |
| Seguridad | revisión solicitada | lectura por defecto |
| Revisión de código | diffs terminados | lectura por defecto |
| Investigación | documentación actual | no modifica código |
