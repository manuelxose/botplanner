# Disciplina de contexto

Graphify es la navegación canónica. No cargues todos los prompts, documentación o
archivos fuente para una tarea localizada. Consulta el prompt aplicable y el subgrafo
relevante, usa lecturas dirigidas, ejecuta validaciones deterministas y resume solo
decisiones persistibles. Los subagentes reciben tarea, consultas/nodos Graphify,
archivos probables y criterios de aceptación; no el repositorio completo.
