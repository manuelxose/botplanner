# Línea base Graphify

Fecha: 2026-09-02

El índice canónico está en `graphify-out/graph.json`. Incluye código TypeScript,
pruebas, manifiestos, documentación, prompts y configuración AI; excluye
`node_modules`, salidas de compilación, cachés y secretos. La actualización normal es
`graphify update .`.

Validaciones representativas: objetivo de producto, modos de búsqueda, procedencia de
precios, pipeline de descubrimiento y módulos impactados por cambios de fechas. Las
consultas se realizan con `graphify query` antes de lecturas amplias.
